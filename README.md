# SENTINEL — Anti-DDoS Systems Engineering

SENTINEL is an anti-DDoS systems-engineering project built around asynchronous background analysis, distributed Redis-backed state, behavioral filtering, and peer threat sharing.

> **Evidence boundary:** the repository's headline detection benchmark is run on a deterministic **CIC-DDoS2019-inspired synthetic/mock dataset** generated by `scripts/generate_mock_data.js`. It is useful as a reproducible engineering stress test, but it is **not** validation on the real CIC-DDoS2019 corpus and does not establish production deployment performance.

## 🔬 Architecture

The current implementation includes:

### 1. **Asynchronous Math Worker Pool**
- **Offloaded Heavy Math**: All O(N²) matrix operations (Neural Net backprop) and FFT signal analysis are offloaded to hardware background threads.
- **Event-loop isolation goal**: the primary Express path keeps heavier analysis out of the request thread; actual latency/throughput depends on deployment and workload.

### 2. **Distributed State (Redis)**
- **Shared state support**: Redis-backed state allows multiple instances to share profiles and reputation data.
- **L1/L2 Caching**: High-speed local memory (L1) combined with persistent Redis (L2) ensures instant IP profiling and reputation lookups.

### 3. **Dynamic Z-Score Filtering**
- **Statistical Baselines**: Replaced static thresholds with self-learning Exponential Moving Average (EMA) and Z-score dynamic baselines.
- **Synthetic benchmark behavior**: the bundled mock benchmark reports precision/recall metrics under its generated traffic model; those values are not real-world detection guarantees.

### 4. **Decentralized P2P Gossip Mesh**
- **Peer threat sharing**: WebSocket-based gossip code propagates threat blocks between configured peers.
- **Proof-of-Threat ledger mechanics**: the project includes signed/validated peer-state concepts as an engineering subsystem; this is not a claim of production consensus security.

## 📊 Synthetic benchmark

The included benchmark is **CIC-DDoS2019-inspired**, not the real dataset. `scripts/generate_mock_data.js` creates deterministic synthetic behavioral rows and `scripts/benchmark_cicddos.js` evaluates the current detection logic against that generated fixture.

The resulting accuracy, precision, recall, and F1 values are therefore **fixture-specific regression/stress metrics**. They are useful for reproducibility and code changes, but should not be interpreted as external DDoS-detection accuracy.

```bash
Request → IP extraction → State Hydration (Redis) → 
Rate Limiter → Behavioral Fingerprinting (Z-Score) → 
Contagion Clustering (LSH) → P2P Threat Sync (Gossip) → 
Bot Verdict → [Fire-and-Forget Neural Training (MathPool)]
```

## 🚀 Quick Start

### Option 1: Pre-built Binary (Recommended)

Download from [GitHub Releases](https://github.com/matthewvaishnav/sentinel/releases/latest):

```bash
# Linux (AppImage)
chmod +x SENTINEL-*.AppImage
./SENTINEL-*.AppImage

# Windows
SENTINEL-x.x.x-Setup.exe

# macOS
open SENTINEL-*.dmg
```

### Option 2: From Source

```bash
# Clone repository
git clone https://github.com/matthewvaishnav/sentinel.git
cd sentinel

# Install dependencies
npm install

# Setup Environment
cp .env.example .env
# Edit .env with your REDIS_URL and P2P_PORT

# Start the Hardened Sentinel
npm start
```

### Supported Node versions

SENTINEL supports **Node.js 18+** (see `package.json` `engines`).

### Automated Releases

GitHub Actions automatically builds all platform packages when you push a version tag:

```bash
# Trigger a new release (patch, minor, or major)
node scripts/trigger-release.js patch

# Or manually:
git tag v1.0.1
git push origin v1.0.1
```

This creates a GitHub Release with pre-built binaries for:
- **Windows**: `.exe` installer + portable executable
- **Linux**: `.deb` package + AppImage + standalone binary  
- **macOS**: `.dmg` disk image + standalone binary

See [RELEASES.md](./RELEASES.md) for detailed release documentation.

### Building Locally

To build platform packages on your machine:

```bash
# Build for all platforms
npm run build:all

# Or specific platforms:
npm run build:win       # Windows
npm run build:linux     # Linux
npm run build:macos     # macOS
npm run build:deb       # Linux .deb package
npm run build:win-setup # Windows installer (requires NSIS)
npm run build:dmg       # macOS .dmg (requires macOS)
npm run build:appimage  # Linux AppImage
```

### Run Synthetic Benchmark
```bash
# Generate the deterministic mock dataset and execute the synthetic benchmark
node scripts/generate_mock_data.js
node scripts/benchmark_cicddos.js
```
